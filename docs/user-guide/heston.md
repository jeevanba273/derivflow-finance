# Heston model

The Heston (1993) model lets the variance follow its own mean-reverting process:

$$dS = (r - q) S\,dt + \sqrt{v} S\,dW_1, \qquad dv = \kappa(\theta - v)\,dt + \sigma\sqrt{v}\,dW_2, \qquad d\langle W_1, W_2\rangle = \rho\,dt.$$

`v0` and `theta` are variances: 0.04 is a 20% volatility. When the Feller condition
2 kappa theta > sigma^2 fails the variance can reach zero; `set_parameters` warns, and the
pricers still work.

## Analytic prices

`analytic_price` integrates the Lewis (2001) single-integral formula with the
characteristic function in the form of Albrecher et al. (2007). It reproduces Alan Lewis's
reference prices to 1.1e-12 and QuantLib's `AnalyticHestonEngine` to 2.1e-10 on 27 cases.

```python
from derivflow import HestonModel, implied_volatility

model = HestonModel()
model.set_parameters(v0=0.04, kappa=2.0, theta=0.04, sigma=0.35, rho=-0.7)
for K in (80.0, 100.0, 120.0):
    price = model.analytic_price(100.0, K, 1.0, 0.03, "call")
    print(
        f"K={K:5.1f}: {price:.4f}, Black-Scholes implied vol {implied_volatility(price, 100.0, K, 1.0, 0.03):.4f}"
    )
```

```text
K= 80.0: 23.7459, Black-Scholes implied vol 0.2299
K=100.0: 9.1746, Black-Scholes implied vol 0.1938
K=120.0: 1.6863, Black-Scholes implied vol 0.1642
```

Negative rho gives the downward-sloping smile above.

## Monte Carlo

`monte_carlo_price` uses Andersen's (2008) quadratic-exponential (QE) scheme by default and
full-truncation Euler (Lord, Koekkoek and van Dijk, 2010) with `scheme="euler"`. The QE scheme
stays close to the analytic price with few time steps even when the Feller condition fails.

```python
mc = model.monte_carlo_price(
    100.0, 100.0, 1.0, 0.03, "call", num_sims=200_000, num_steps=100, random_seed=1
)
lo, hi = mc.confidence_interval
print(f"analytic {model.analytic_price(100.0, 100.0, 1.0, 0.03):.4f}")
print(f"QE Monte Carlo {mc.price:.4f}, 95% CI [{lo:.4f}, {hi:.4f}]")
```

```text
analytic 9.1746
QE Monte Carlo 9.1562, 95% CI [9.1070, 9.2055]
```

## Calibration

`calibrate_to_market` fits the five parameters to option prices by bounded least squares on
the analytic prices. The example fits quotes generated by the model itself, so it checks the
optimiser rather than the model's fit to market data.

```python
quotes = [
    {"K": K, "T": T, "price": model.analytic_price(100.0, K, T, 0.03, "call")}
    for T in (0.25, 1.0)
    for K in (85.0, 100.0, 115.0)
]
result = HestonModel().calibrate_to_market(quotes, S=100.0, r=0.03)
print({k: round(v, 4) for k, v in result["parameters"].items()}, f"rmse {result['rmse']:.1e}")
```

```text
{'v0': 0.04, 'kappa': 2.0, 'theta': 0.04, 'sigma': 0.35, 'rho': -0.7} rmse 1.2e-14
```

The model has no jumps, so it fits very short-dated smiles poorly, and a good least-squares
fit does not imply stable parameters across dates.
